<CaseSection number="02" title="Constraints">
  <p>The system needed to support three brands, existing live journeys and inconsistent legacy components while moving designers from Tokens Studio to native Figma Variables.</p>
  <p>I had to balance standardisation with enough flexibility for different product needs, while resolving variable, publishing and component conflicts as the system evolved.</p>
</CaseSection>

<CaseSection number="03" title="Finding the friction" layout="two-column">
  <CaseItem>
    <CaseItem title="Data used">
      <p>7,609 recorded component inserts, used to estimate time saved.</p>
    </CaseItem>
    <CaseItem title="Research">
      <p>Audit of repeated patterns and inconsistent component states across the apps.</p>
    </CaseItem>
    <CaseItem title="Key insight">
      <p>Many components could be consolidated into shared foundations rather than rebuilt per brand.</p>
    </CaseItem>
  </CaseItem>
  <CasePlaceholder />
</CaseSection>

<CaseSection number="04" title="Exploring options">
  <p>Compared the existing Tokens Studio workflow with native Figma Variables. Variables enabled native theming and reduced reliance on third-party tooling.</p>
</CaseSection>

<CaseSection number="05" title="The design" layout="three-column">
  <CaseItem title="Atomic foundations" placeholder>
    <p>Rebuilt components from atomic foundations using Figma Variables.</p>
  </CaseItem>
  <CaseItem title="Aligned with code" placeholder>
    <p>Worked with engineering so component and variable logic reflected how the UI was built.</p>
  </CaseItem>
  <CaseItem title="Prove it in practice" placeholder>
    <p>Created the My O2 App master file and was the first to implement the new variables in a live app design file.</p>
  </CaseItem>
</CaseSection>

<CaseSection number="06" title="Outcome and next steps">
  <p>Across 7,609 recorded component inserts, the new approach was estimated to save 5–6 hours per designer each year while creating a more scalable cross-brand foundation.</p>
  <p>Next, learnings from the App Library will feed into the wider CDS, shaping shared variable structures, component patterns and governance across Virgin Media and O2.</p>
</CaseSection>
